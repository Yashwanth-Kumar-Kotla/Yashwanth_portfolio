AutoShorts

AutoShorts uses YouTube API Services.

AutoShorts is a personal automation tool built by Yashwanth Kumar Kotla. It creates short vertical videos (YouTube Shorts), uploads them to my own YouTube channels through the YouTube Data API v3, posts one comment from my own channel on each of those videos, then reads YouTube Analytics reports so I can see how those videos perform. It is not a public service. The only person who signs in with Google is me, the owner of the channels it publishes to.

Who it is for

AutoShorts is used only by its owner, for the owner's own YouTube channels. It does not offer accounts to other people and does not access anyone else's channel.

Google and YouTube data it accesses

When I sign in with Google, AutoShorts asks for these permissions:

  • Upload videos (youtube.upload): to publish the Shorts it creates to my channel.
  • View YouTube account details, read only (youtube.readonly): to read my channel and video metadata, such as titles and upload status, so it knows what has already been published.
  • Manage YouTube account, comments only (youtube.force-ssl): used only to post one comment from my own channel on each of my own videos (commentThreads.insert). It is not used to read, edit, or delete comments, or to act on anyone else's videos.
  • View YouTube Analytics reports, read only (yt-analytics.readonly): to measure how my videos perform, such as views and watch time, so I can improve future videos.

This data is used only to publish videos and comments to my own channels and to measure their performance. It is never sold, shared with third parties, or used for advertising.
